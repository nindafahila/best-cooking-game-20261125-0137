**Warung Kilat — Dapur Nusantara**: game masak cepat di warung Indonesia. Pelanggan memesan hidangan Nusantara (Nasi Goreng, Mie Ayam, Sate Ayam, Gado-Gado, Ayam Geprek, Es Teh Manis); pemain meracik bahan di meja, memasak di kompor, dan menyajikan sebelum pelanggan kehabisan sabar. Shift 3 menit, 3 hati, kombo menaikkan skor, dan tekanan yang makin naik tiap level.

## Run it

```sh
node serve.ts
# lalu buka http://localhost:8080 di desktop Chrome
```

Game berjalan dari berkas statis di `game/` tanpa jaringan. Tangkapan layar di `screenshots/` diambil dari adegan demo game itu sendiri (`?shot=cover|cook|serve|rush`).
